# Humboldt MineOps

Field operations and MSHA compliance system for underground mining operations.

## Core Operational Workflow
Production Log → Ore Sacks → Staging Board → Truck Loading → Outbound Shipments

## Operational Features
- Production logging
- Ore sack tracking
- Staging board
- Truck loading & shipment assignment
- Shipment traceability
- Shift handoff

## MSHA Compliance Features
- Workplace Exams
- Hazards
- Corrections
- Incident Reporting
- Training Records
- Certificate Tracking
- Surface Annual Refresher Tracking
- Underground Annual Refresher Tracking
- Inspection Reporting

## Design Priorities
- Offline-first workflows
- Rugged field usability
- Large touch targets
- Low typing
- Fast operational entry
- Inspection readiness
- Inspection-ready audit trails
